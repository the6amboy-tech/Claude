# Growing Asharas in search

The site now ships the technical foundations Google needs to understand and index it:

- A descriptive `<title>` and meta description targeting **"Asharas music"**
- Open Graph + Twitter cards with a branded `og-image.png` (rich link previews)
- `WebSite`, `Organization`, `WebApplication`, founder, and logo structured data
- A consistent **Asharas** site name, **Asharas Music** alternate name, and “Music, in sync.” brand line
- A square, crawlable 512px organization logo plus SVG/PNG favicons at stable URLs
- `robots.txt` (allows crawling) and `sitemap.xml`
- A canonical URL and indexable static text (brand name, tagline, sections)

These changes improve eligibility; they cannot guarantee a particular Google result or ranking. Google must recrawl the site before the new logo or favicon can appear, which can take days or weeks.

## Do this to get indexed (~10 minutes)
1. Go to **Google Search Console** → <https://search.google.com/search-console>.
2. Add or open the domain property for **`asharas.in`**. The homepage already contains a Google verification meta tag.
3. In Search Console → **Sitemaps**, submit **`https://www.asharas.in/sitemap.xml`**.
4. Use **URL Inspection** for **`https://www.asharas.in/`**, run the live test, then select **Request indexing**.
5. Check the Page indexing and Core Web Vitals reports after Google has collected data.

Then search `site:asharas.in` in a few days to confirm indexing, and track queries such as `asharas` and `asharas music` in Search Console’s Performance report.

## Honest expectations about ranking
- **Indexing ≠ ranking.** Being in Google is quick; ranking #1 for "asharas
  music" depends on competition and how strong the site's signals are.
- **Earn relevant mentions.** Use the new `og-image.png` when sharing Asharas from your GitHub profile, LinkedIn, Instagram, X, music communities, and product directories. Keep the name and URL identical everywhere.
- **Publish useful pages.** Search engines have little text to rank in a single-page player. Original public pages about supported languages, synced lyrics, Listen Together, playlists, and product updates can earn long-tail traffic.
- **Measure, then iterate.** Review Search Console queries and pages monthly. Improve pages that already receive impressions instead of stuffing unrelated keywords.
- **Performance and trust matter.** Keep the app fast, mobile-friendly, HTTPS-only, and clear about data use and music sources.

Avoid paid backlink schemes, copied lyrics pages, mass automated posts, and keyword stuffing; they can damage search visibility and user trust.
